Agents and free AI

opencode-free-stack

routing · fallback · quota

Free model tiers fail in three ways — RPM caps, daily token pools, model weight. This router knows all three and moves the request to the next free model in the same turn.

npm i -g opencode-free-stack

free-tier-tracker

quota · limits · alerts

A local ledger of what every free tier has left. It learns from the 402 you already hit and tells the agent to stop using a provider that is done for the day.

npm i -g free-tier-tracker

prompt-budget

tokens · cost · context

Every request re-sends your system prompt, the tool schemas and the rules file. This measures all of it before you ship it, and says what to cut.

npm i -g prompt-budget

agent-cost-guard

budget · proxy · guardrails

Agent loops are unbounded. A proxy in front of any OpenAI-compatible endpoint enforces a token budget, a spend budget, a round cap and a latency ceiling.

npm i -g agent-cost-guard

MCP infrastructure

agent-browser-mcp

browser · automation · agents

A real browser for agents — navigation, reading, clicking, typing — with Cloudflare and captcha handling under an explicit budget and allowlist.

mcp-doctor

diagnostics · healthcheck

MCP servers break silently. This probes every server you configured, lists its tools, measures latency and names the exact failure.

npm i -g mcp-doctor

mcp-proxy

proxy · auth · logs

One endpoint in front of many MCP servers: a client key, per-client rate limits, an append-only log, replay of past calls, routing by server.

npm i -g mcp-proxy

tool-schema-lint

linting · tool-use

Agents call tools wrongly because the schema is ambiguous. This lints the descriptions, the optional parameters and the free-form strings, and rewrites them.

npm i -g tool-schema-lint

free-web-mcp

mcp · web · zero credits

Web search and page reading for agents with no API credits: r.jina.ai, Wikipedia, Hacker News and GitHub behind one MCP server.

npm i -g free-web-mcp

Crypto and safety

agent-x402

x402 · usdc · policy

Pay per API call in USDC with no account and no key — and a spend policy (daily cap, per-request cap, payee allow-list) that a prompt injection cannot talk its way past.

npm i -g agent-x402

x402-priceboard

pricing · discovery

Every x402 server answers the first request with its price, network and payee. This builds the price board without paying anything.

npm i -g x402-priceboard

prompt-injection-guard

security · scanner

The files an agent reads by itself may contain hidden instructions. This scans rules, skills and tool descriptions for overrides, invisible characters and embedded commands.

npm i -g prompt-injection-guard
