Как на этом зарабатывают

Пятнадцать open-source проектов, один публичный сервис с оплатой за запрос и своя цепь. Все поступления идут в один кошелёк — тот же, что импортирован в MetaMask.

Кошелёк

0x8aC6a229f254980CCd3Dd35CF5E1B7c08880B40E — сеть Base

Каналы

работает Платный MCP-эндпоинт (x402)

Веб-поиск и чтение страниц: 30 запросов в час бесплатно, дальше 0.001 USDC за вызов. Оплата подписывается EIP-3009, деньги реально забираются на кошелёк выше.

/mcp — бесплатно, /mcp/paid — за оплату.

работает Lumen — своя криптовалюта

PoS-цепь со своим AMM: ликвидность в протоколе, обмен без биржи, keeper сам покупает LMN за USDC через Uniswap V3 на Base.

Доход: комиссия пула (0.3%) и начисления валидаторам.

в работе npmjs.org — дистрибуция

Публикация 15 пакетов даёт главный канал установки: npm i -g, трафик из npm и GitHub, звёзды, спонсоры.

Нужен один клик в npm UI и node scripts/npm-publish.mjs.

в работе GitHub Sponsors и донаты

Кнопка Sponsor подключена во всех репозиториях, адрес для USDC — в каждом README.

ждёт Баунти за contributions

Ишью с меткой 💰 Reward в 15 репозиториях: выплату даёт тот, кто профинансировал задачу через /reward, и получает её автор merged-PR.

в работе Платные тарифы агентских сервисов

agent-browser-mcp, mcp-doctor, agent-cost-guard — всё это можно продавать по подписке или за запрос, тем же способом, что и x402.

Что нужно, чтобы пошли деньги

  1. На кошелёк 0x8aC6…0B40E — около 0.02 ETH в сети Base: это газ для сбора USDC и для деплоя контрактов Lumen.
  2. Один клик в npm UI: выдать токену права на организацию @rustemmustafingovua-byte — и node scripts/npm-publish.mjs опубликует все 15 пакетов.
  3. Немного USDC в казну — чтобы наполнить пул LMN/USDC в Uniswap: без ликвидности keeper не сможет покупать.
  4. Подтвердить sudo-режим GitHub (GitHub Mobile или код на почту) и включить Sponsors.

Команды

node scripts/money.mjs            # панель денежных каналов: где сколько и что мешает
node scripts/deploy-lumen.mjs     # деплой Lumen в Base + пул Uniswap + запись keeper.json
node scripts/npm-publish.mjs      # публикация всех пакетов на npmjs.org
node scripts/status-page.mjs --save  # живая страница статуса портфеля
bash install.sh                   # установка всего набора одной командой
